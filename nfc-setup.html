NFC tag setup (owner tool)

The address every tag and QR code must contain

Option A: write the tag from this page

  1. Open this page in Google Chrome on Android (not Samsung Internet) over HTTPS.
  2. Switch NFC on in Android settings.
  3. Tap Write to NFC tag, then hold a blank NTAG213/215/216 tag on the back of the phone until you see “Written”.

Option B: any phone, free app

  1. Install NFC Tools (wakdev) from Google Play or the App Store.
  2. Write › Add a record › URL / URI › paste the address above.
  3. Tap Write and hold the tag to the phone.
  4. Optional, once you are happy: Other › Lock tag (permanent, cannot be undone).

This page only writes to a tag you hold against your own phone. It stores nothing and sends nothing anywhere.
